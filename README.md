# Progetto HTML-CSS: Discord

### Continuo della repository: htmlcss-struttura-discord

## Descrizione

Questo progetto è una riproduzione statica di una landing page ispirata a Discord, sviluppata con HTML e CSS.

### Struttura e contenuti principali:
- **Header**: composto da una barra superiore con logo, navigazione principale e pulsante di login, e una sezione inferiore con titolo, descrizione e pulsanti di download/apertura browser.
- **Main**: una serie di card informative che illustrano le funzionalità di Discord (come la gestione dei server, canali vocali, community, tecnologia audio-video), separate da onde decorative per migliorare il design e la leggibilità.
- **Footer**: con più colonne di link organizzati per categorie (Prodotto, Compagnia, Risorse, Norme), icone social e pulsante per la registrazione.

### Aspetti tecnici:
- Utilizzo di flexbox per l’allineamento e il layout responsivo delle sezioni.
- Implementazione di bottoni stilizzati con classi per colori diversi.
- Inserimento di immagini di sfondo e icone social tramite font-awesome.
- Separazione chiara delle sezioni per una buona esperienza utente visiva.
